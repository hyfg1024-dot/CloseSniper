# 尾盘狙击 · CloseSniper

面向 A 股“14:30 尾盘观察、次日早盘退出”思路的免费筛选工具。英文项目名为 **CloseSniper**。它先用涨幅、量比、换手率和流通市值做硬过滤，再检查成交量、均线、分时均价线、尾盘回踩与热点概念。

> 本项目只用于学习和策略研究，不连接券商、不自动下单，也不构成投资建议。免费行情可能延迟或中断，请在交易前以券商行情为准。

## macOS 一键启动

1. 在 GitHub 页面选择 **Code → Download ZIP**，解压。
2. 双击 `启动尾盘雷达.command`。
3. 首次启动会创建 `.venv` 并安装依赖，通常需要几分钟；以后会直接启动。
4. 浏览器打开后，在交易日 14:30–15:00 选择严格或理性流程扫描。

今日筛选提供两个入口：

- **严格标准扫描**：按初始标准要求现价 ≥ MA5 > MA10 > MA20 > MA60，且四条均线均较 5 日前上升；仅作对照，不写入次日校验。
- **理性流程扫描（推荐）**：合并当日实时行情为临时日K，要求现价 ≥ MA5 > MA10 > MA20、MA5/10/20向上且现价在 MA60 上方；MA60上升用于加分排名。
- 页面倒计时会提醒 14:30 首次观察、14:45 复核和 14:52 最终扫描。
- 双击 `安装每日校验.command` 后，macOS 会在三个尾盘节点自动执行理性流程；14:52仍入选的股票按 `20% × 14:30评分 + 30% × 14:45评分 + 50% × 14:52评分` 排序，缺席节点按 0 分计算。
- 14:52综合名单是唯一进入次日校验的名单；只在早期出现、14:52已掉队的股票不会进入校验。
- “今日筛选”把严格标准与理性流程的当日结果分别固定在两个扫描按钮下方；后台每个节点会同时更新两种口径，避免用不同时间的数据做横向比较。
- 页面分别保留并展示14:30、14:45、14:52三个时点的原始结果，最后单独展示三时点评分加权后的最终名单；零候选节点也会明确标记为已执行。
- 次日取得行情后，理性流程综合名单会连同三次评分、持续性标签及早盘收益一起显示在“次日校验”。
- 自动任务部署在 `~/Library/Application Support/CloseSniper`，不依赖网页保持打开；14:30和14:45静默采样，14:52保存严格标准结果并生成理性流程综合结果。
- 自动任务依赖Mac在对应时点保持开机且未休眠；免费行情无法确认当日指数分钟数据时会放弃存档，避免节假日或陈旧行情形成假信号。

### 次日校验

- 交易日14:30、14:45分别保存观察快照，14:52才冻结综合候选名单；记录保存在本机 `data/panpanc.db`，不会上传 GitHub。
- “次日校验”分别显示次一交易日 9:30、9:45、10:30 收益，以及 15 分钟和 60 分钟区间的最高收益与最大回撤。
- 次日 9:30–9:50 可点击早盘按钮：9:45前保存开盘与点击时快照，9:45后完成固定口径校验；只有固定9:45数据进入历史统计。
- 同一自动任务还会在每个工作日9:45和10:30分阶段运行校验；错过校验时可在“次日校验”页面补算。
- “历史表现”对比 9:30、9:45、10:30 胜率、60分钟冲高概率和逐日表现；零候选日也会留档。

如果 macOS 提示无法打开，可在终端进入项目目录执行：

```bash
chmod +x 启动尾盘雷达.command
./启动尾盘雷达.command
```

要求：macOS 12 或更高版本、Python 3.11 或更高版本、可访问互联网。

## 运行逻辑

硬条件默认值：

- 当日涨幅 3%–5%
- 量比 ≥ 1
- 换手率 5%–10%
- 流通市值 50亿–200亿元
- 排除 ST / *ST、退市整理、上市首日 N/C、北交所股票

技术确认：

- 近 5 日量能总体阶梯放大
- 收盘价 ≥ MA5 > MA10 > MA20 > MA60，均线同步上行
- 至少 70% 分钟价格在成交均价线上方
- 个股日内涨幅高于同期上证指数
- 最新价不破均价线，距最近 30 分钟高点不超过 1.2%
- 实时涨幅前六的概念板块作为加分项

结果会先列出“候选”，再列出“观察”；同组按 100 分策略匹配度从高到低排序，并展示每只股票的主要优势。

全部参数可在左侧调整。程序最多对硬过滤排名靠前的 30 只股票抓取日线和分时，以控制免费接口请求量。

## 开发运行

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

离线检查界面时，打开左侧“演示数据”。运行测试：

```bash
python -m unittest discover -s tests
```

## 数据源

使用 [AKShare](https://github.com/akfamily/akshare) 及公开行情接口，无需 API Key。当前主链路为新浪全市场实时行情、腾讯前复权日线和新浪分钟行情；东方财富作为备用源。量比由今日累计成交量相对近 5 日同期预期成交量计算。接口并非交易所授权的专业行情服务，稳定性和时效性不作保证。
